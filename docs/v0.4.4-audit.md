- Push bildirim veri modeli ve Edge Function gönderim altyapısı var; Expo Go Android'de uygulama kapalıyken production remote push doğrulanamaz.
- Acil Durum Zinciri kişi ve öncelik modeli var; cevap yoksa süre bazlı ardışık background eskalasyon worker'ı henüz production olarak çalışmıyor.
- DraBornPark+ entitlement/RLS/trial altyapısı var; gerçek Google Play Billing satın alma ve purchase-token doğrulaması henüz bağlı değil.
- Tanık Modu metin/olay akışı var; public web fotoğraf/video medya yükleme hattı production olarak tamamlanmadı.
- DraBorn AI mesaj güvenliği şu anda deterministik maskeleme/nötrleştirme kullanıyor; tam LLM moderasyonu bağlı değil.

## Güvenlik denetimi

- DraBornPark SQL RPC'lerinin `anon EXECUTE` yetkisi kapalıdır.
- Public ziyaretçi akışı doğrudan SQL RPC yerine Edge Function üzerinden çalışır.
- Factory RPC'leri authenticated + `drabornpark_is_admin()` kontrolü kullanır.
- Public destek/hesap-silme istek tabloları RLS açık ve istemci politikası olmadan service-role kullanımına kapalı tutulur.
- Supabase Security Advisor'daki DraBornGarage/workshop uyarıları bu sürümde değiştirilmemiştir.
- Supabase Auth leaked-password protection proje ayarında kapalı görünüyor. Bu ayar kod/SQL migration değil Auth platform ayarıdır ve yayın öncesi Supabase Auth güvenlik ayarlarından açılmalıdır.

## Performans notu

DraBornPark'ın bazı indexleri Security/Performance Advisor tarafından `unused_index` olarak raporlanıyor. Proje yeni/düşük trafik olduğu için bu tek başına kaldırma gerekçesi değildir; sorgu kullanımı oluşmadan indexler silinmemiştir.
